# 针对 CNN 模型的攻击练习

本仓库存放了以课程实验为基础的基于 MindSpore 框架的对 CNN 模型的攻击实践代码，包括利用 FGSM 算法生成对抗样本并干扰模型输出、训练后门模型并通过触发器干扰模型输出、逆向恢复模型训练数据的实践。

## 环境依赖

- MindSpore 框架版本： `2.8.0`
- Python 版本： `3.12`

## 运行测试

执行以下命令即可运行测试文件，分别从对抗样本生成、模型后门植入与利用、模型数据逆向三个方面对 CNN 模型进行攻击测试。

```bash
make test
```

执行以下命令即可清理测试过程中生成的权重、样本和结果等文件。

```bash
make clean
```
